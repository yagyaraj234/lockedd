Locked — Android App Blocker

Free Android app blocker (Opal/One-Sec style). Native Kotlin AccessibilityService intercepts blocked app launches and shows a full-screen blocking overlay. Two unlock modes: Temporary (5-min breathing delay) or Physical (walk N steps, customizable goal, daily reset). Prevention Mode blocks uninstall with a 12-hour disable cooldown. Expo bare workflow + local Kotlin modules. No paywall, no server.

TL;DR
Kotlin AccessibilityService + React Native UI — blocks apps at the OS level, free forever.

Risks 4

AccessibilityService is killed by aggressive battery optimization on some OEMs (Xiaomi, Samsung)
mitigated by battery optimization exempt request in onboarding + foreground service with persistent notification
TYPE_WINDOW_STATE_CHANGED fires on dialogs/keyboards, not just app launches
need to filter by packageName change only
getInstalledApps() on Android 11+ requires QUERY_ALL_PACKAGES permission
must declare in AndroidManifest.xml (Google Play may flag this, but sideload/direct APK is fine)
Step counter resets on reboot
need to persist last known count and accumulate delta

Preconditions

  • Expo SDK 56 project already scaffolded (package.json present, node_modules installed)
  • Physical Android device available for testing (emulator cannot test AccessibilityService or step counter)
  • Android Studio installed for Kotlin builds
